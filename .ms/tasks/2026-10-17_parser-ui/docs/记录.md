# 抖音解析修复与页面重构

日期：2026-10-17
状态：已实现并部署

## 目标

修复同步解析响应未映射视频流的问题，并重构页面，使用户解析成功后可查看作品信息、预览和下载视频。预览不自动播放。后续按用户要求切换到 `dy.pygojrc.cyou`，移除旧域名，不做跳转；下载文件名采用标题、作者和发布时间，并提供复制、直接下载和代理下载。

## 实施

- Worker 同步解析请求增加 `include_raw: true`，同时兼容 `data.media.streams` 与原始 `video.bit_rate`。
- 页面支持从抖音分享文案提取 HTTPS 抖音链接；解析后展示作者、作品 ID、发布时间、时长、互动数据及视频规格。
- 每个视频规格提供预览、直接下载和代理下载；解析后不会预加载媒体，只有用户点击预览才开始加载与播放。
- Worker 仅调用 `demo.douyin.wtf` 解析；代理下载使用 30 分钟有效的 HMAC 签名令牌、媒体域名白名单、手动校验重定向、Range 转发和流式响应。
- 文件名按 `主题_作者_发布时间.mp4` 生成，发布时间按北京时间格式化；发布时间缺失时留空。非法字符、尾随点空格和 Windows 保留名均经过处理。
- 页面新增文件名复制按钮；旧 `duoyin.pygojrc.cyou` 未配置保留或跳转。

## 预览与代理下载 403 根因调查

- 使用用户提供作品 ID 在生产页面复现：解析成功，返回 5 个视频规格；点击预览时 `/api/preview` 返回 502，点击代理下载时 `/api/download` 返回 502，正文均错误地描述为“上游视频地址已失效”。
- 浏览器 Network 记录显示媒体请求发往 `v5-dy-ov-experiment.zjcdn.com`，并报告 `net::ERR_BLOCKED_BY_ORB`。页面发出的请求 `Referer` 是本解析站 `https://dy.pygojrc.cyou/`，Worker 的 `fetchMedia` 会将其原样转发。
- 对同一签名媒体地址进行 `Range: bytes=0-0` 对照请求：`Referer: https://dy.pygojrc.cyou/` 返回 `403 text/html`；省略 Referer 返回 `206 video/mp4`；使用 `Referer: https://www.douyin.com/` 也返回 `206 video/mp4`。探测只读取单字节范围，未记录或展示签名查询参数。
- 根因已证实：媒体 CDN 拒绝了来自解析站域名的 Referer；Worker 把用户浏览器请求自身解析站的 Referer 原样代理给 CDN，造成预览与代理下载均 403。错误提示把 403 误报成失效链接也是需单独改进的问题。
- 本轮仅调查并更新本记录，未改动 Worker 行为；修复方向为不转发解析站 Referer（省略 Referer 已验证 206）或按上游允许值设置 Douyin Referer，并区分 403 与真实失效状态。
